# yoicks とは

*Yoicks* は、狩人が猟犬の群れを先へ駆り立てる掛け声です。

yoicks は、たくさんのコーディングエージェントを、そのうちの 1 つを通して同時に動かすための
[herdr](https://herdr.dev) プラグインです。仕事は **orchestrator** に渡します。**Home** で話しかける Claude Code の
エージェントで、残りを並行して進めます:

- **ワーカーを起動します。** タスクごとに 1 つ (`yoicks agent start`)。どれも新しい herdr のタブで動き、同じリポジトリで
  ほかと並行してコードを変更するものは、リポジトリの隣に作る専用の git worktree (`<repo>-wt-<branch>`) で動きます。ワーカーが終わると、ブリッジはそのために
  開いたタブを閉じます。worktree のワーカーのタブは、ブランチがマージされて `yoicks worktree remove` が worktree、
  タブ、ブランチを消すまで残ります。
- **ワーカーを追いかけます。** ワーカーが終わるか、答えを待って止まると orchestrator が起き、結果を読んで次のタスクを
  渡すか、ワーカーが何を待っているかをあなたに伝えます (答えるのは、そのワーカーのペインです)。
- **あなたが要るものだけを持ってきます。** Home の **Needs you** に、そのアカウントの止まっているエージェントと
  orchestrator 自身の質問が並びます。[ヘッドレス](./guide/headless)の orchestrator は、PR のマージ、ログイン、判断など、
  あなたにしかできないことをやることリストに残し、期日が来たらそれぞれ一度だけ知らせます。
- **マージの先まで進めます。** `pr_watch` ([設定](./reference/config)) を有効にすると、ヘッドレスの orchestrator は
  やることリストにある PR のマージに気づき、そのリポジトリでのデプロイを自分の rules が許していればデプロイし、
  ワーカーを片付けます。
- **自分のアカウントの中だけで動きます。** orchestrator が見て動かせるのは、自分の Claude アカウントのエージェント
  だけです。仕事用と個人用の Home を分けておけます ([orchestrator](./guide/orchestrators))。

## 手元から {#in-your-hand}

プラグインは小さなローカルブリッジサーバー (Go のバイナリ) を起動し、モバイル向けの PWA を配信します。
スマホや PC のブラウザから、すべてを扱えます:

- すべてのワークスペースにまたがる全エージェントのダッシュボード。ライブなステータス表示
  (idle / working / **blocked** / done) で、blocked のエージェントは先頭にソートされます。
  done のエージェントをスマホで開くと、スマホ上では idle と表示されます (herdr 側の状態は変えません)。
  各カードに git ブランチ名が表示され、リンクされた worktree のエージェントは
  メインチェックアウトのリスト内に worktree チップ付きで表示されます
- スマホからエージェントの名前を変え、clear し、止められます。各ペインの **⋮** メニューで名前の変更、
  clear (新しいセッション)、停止ができます (orchestrator の Home では、ステータスバー (PC ではいちばん上のバー) の **⋮** に **Clear** と **Stop**、
  ヘッドレスのものでは **Compact** もあります)。PC のブラウザでは **⋮** に **Open in herdr** もあり、
  PC の herdr がそのエージェントのワークスペース、タブ、ペインに切り替わります。エージェントを起動するのは orchestrator で、手で起動するものではありません。
  右上 (PC ではサイドバーの上端) の **⚙** で設定を開きます
- ペイン表示: 端末出力をスマホ幅に合わせてカラー表示。ピンチズーム、下スワイプで
  スクロールバック、複数行入力、クイックキー (Enter、⌫、Esc、Ctrl+C、矢印、y/n、…)。
  PC のブラウザでは Enter で送信、Shift+Enter で改行です。スマホでは Enter で改行し、Send で送信します
- WebSocket によるライブ更新 (サブ秒)。アプリがバックグラウンドにある間にエージェントが blocked か
  done になると、OS の通知が出ます (Settings で設定)。タップでそのペインへジャンプします
- アカウント不要・クラウド不要・サードパーティサービス不要。すべてが自分のマシン内で完結し、
  リモートアクセスの経路は自分で選べます — リバースプロキシ、トンネル、または VPN。

```
Android (Chrome / インストールした PWA)
   │  リバースプロキシ / トンネル / VPN 経由の HTTPS (「スマホへの公開」を参照)
   ▼
ブリッジサーバー (本プラグイン、127.0.0.1:8390 で待ち受け)
   │  herdr の unix ソケット上で ndjson
   ▼
herdr サーバー
```
